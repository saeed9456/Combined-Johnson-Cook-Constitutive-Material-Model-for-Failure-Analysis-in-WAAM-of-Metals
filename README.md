# Combined-Johnson-Cook-Constitutive-Material-Model-for-Failure-Analysis-in-WAAM-of-Metals
This UMAT user subroutine implements a material model in Abaqus that predicts residual stress distribution, warpage, and deformation throughout the wire arc additive manufacturing of metals. It integrates the Johnson-Cook material model with Von Mises failure model to predict the stress and deformation buildup during the WAAM process.
